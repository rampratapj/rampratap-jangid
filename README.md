# Rampratap Jangid — Portfolio

Personal portfolio website for Rampratap Jangid, focused on QA automation engineering, Selenium, Java, TestNG, CI/CD, API testing, and enterprise quality systems.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome
- Google Fonts

## Features

- Responsive portfolio layout
- Animated UI interactions
- Custom QA-themed hero section
- Experience timeline
- Project showcase
- Skills visualization
- Contact integration via mailto
- Mobile-friendly navigation

## Local Development

Open `index.html` directly in a browser, or serve locally:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
